# Посмотри в окно

Проектная работа Яндекс Практикума. Приложение показывает видео из окон в разных городах: можно выбрать город и время суток, переключать ролики по карточкам и подгружать новые кнопкой «Показать ещё».

Разметка и логика на JavaScript были в заготовке. В рамках проекта свёрстаны стили в `styles/style.css` по макету в Figma.

## Что сделано

- Лейаут страницы на Flexbox: блок с видео и формой поиска слева, заголовок и список карточек справа.
- Видео и превью карточек подогнаны под размеры через `object-fit` и `object-position`.
- Состояния интерактивных элементов: `:hover`, `:active`, `:focus-visible`. Обводка лейбла при навигации с клавиатуры сделана через `:has(:focus-visible)`.
- Прелоадеры и сообщение об ошибке встают поверх своих блоков благодаря `position: relative` у контейнеров.

## Технологии

- HTML5
- CSS3: Flexbox, псевдоклассы и псевдоэлементы, `object-fit`, `line-clamp`, `:has()`
- JavaScript (логика приложения из заготовки)

## Как запустить

Откройте `index.html` в браузере. Видео и карточки подгружаются с сервера Практикума, поэтому нужен доступ в интернет.
