# Посмотри в окно

Проектная работа по вёрстке в рамках обучения в **Яндекс Практикуме**.

«Посмотри в окно» — веб-приложение, которое позволяет посмотреть видеозаписи из разных городов и выбрать время суток.

## Возможности

- Поиск видеозаписей по названию города.
- Фильтрация по времени суток: утро, день и ночь.
- Просмотр найденных роликов и переключение между карточками.
- Загрузка дополнительных карточек кнопкой «Показать ещё».
- Отображение индикатора загрузки и сообщения об ошибке.

## Что сделано в проектной работе

- Сверстана страница по макету Figma.
- Настроена раскладка блоков с использованием Flexbox.
- Оформлены форма поиска, чекбоксы, кнопки и карточки видеороликов.
- Реализованы стили для состояний наведения, нажатия и клавиатурного фокуса.
- Настроено отображение видео и изображений с помощью `object-fit`.
- Подготовлены контейнеры для прелоадера, списка карточек и сообщения об ошибке.

HTML-разметка и JavaScript-логика предоставлены в стартовом проекте. Основная задача работы — оформление интерфейса с помощью CSS без нарушения существующей функциональности.

## Технологии

- HTML5
- CSS3 (Flexbox, псевдоклассы, псевдоэлементы)
- JavaScript (логика из стартового проекта)
- Git и GitHub

## Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/vlad-byte7/posmotri-v-okno-ad.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd posmotri-v-okno-ad
   ```

3. Откройте файл `index.html` в браузере.

Для загрузки видеороликов требуется подключение к интернету.
